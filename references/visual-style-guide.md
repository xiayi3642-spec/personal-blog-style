# 视觉风格指南

> L6 视觉分析。已逐张检查 `reference_images/01.png`—`08.png`。

## 样本判断

8 张图片是同一篇长文的连续页面截图，承担的是目标版式展示，而非正文内部配图。因此不能据此推断“每篇文章配 8 张图”。能确定的是：文本型呈现、较宽松行距、长段落与黄色标题高亮共同构成主要视觉识别。

## 配图策略

- 默认不强制配图。文章依靠具体叙事和概念推进成立。
- 需要配图时，优先证据型与演示型：原始材料、对话截取、工作流程、数据、引用出处。
- 图片不代替关键结论；图片里若有精确数据，正文至少概括其意义。
- 建议每 600—1000 字最多一张承重图，除非文章本身是过程演示。
- 不使用无信息量的 AI 氛围图填空。

## 排版格式

- 白底、深灰或近黑正文，整体素净。
- 正文为较大的无衬线中文字体，视觉上约 20—24 px；行高约 1.7—1.9。
- 段落之间用一个完整空行分隔，不首行缩进。
- 段落偏长，常为 4—8 句；关键判断可以单独成段或整句加粗。
- 小标题不是目录标签，而是本轮思考的自然提问，例如“为什么想写这个话题”“关于 taste 和手搓之间的联系”。
- 标题文字深灰、粗体，背后使用低饱和淡黄色矩形高亮；高亮紧贴文字，不铺满整行。
- 层级宜少：文章标题 + 2—5 个小标题 + 正文。避免三级以上标题树。

## 加粗与强调

- 每 800—1200 字最多 1—3 处强强调。
- 优先加粗完整判断句，如“有时候差别真的就在毫厘之间。可也恰恰是这种毫厘之间的东西，最见功夫。”
- 不连续加粗多个段落，不把所有概念词逐个高亮。
- 英文概念可保留原样，但不使用彩色、斜体等额外装饰叠加。

## 色彩

| 角色 | 建议 |
| --- | --- |
| 页面背景 | `#FFFFFF` |
| 正文 | `#25282D` 或相近深灰 |
| 标题文字 | `#60656B` |
| 标题高亮 | `#FFF39A` 或相近低饱和浅黄 |
| 次要说明 | 中灰，不另设强调色 |

整体保持黑白为主、淡黄单点强调。不要引入多种品牌色。

## Markdown 实现建议

```markdown
## 为什么想写这个话题

正文保持自然段，不一句一行。

**只在真正承重的判断上使用整句加粗。**
```

Markdown 本身无法稳定实现标题背景色；若发布平台支持 HTML/CSS，可为二级标题内文字设置淡黄 `background`，并保留适度内边距。
