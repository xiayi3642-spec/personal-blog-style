## 高频语义词群

| 频率 | 词群 | 典型词 | 功能 |
| --- | --- | --- | --- |
| 高 | 思考动作 | 想、判断、追问、理解、知道、意识到、看出来 | 让文章呈现判断的形成过程 |
| 高 | 过程与积累 | 手搓、慢慢、过程、训练、积累、留下、形成 | 把能力解释为长期生成物 |
| 高 | 能力对象 | 判断力、分寸感、专注、手感、品味、尺度 | 为模糊经验命名 |
| 高 | 转折推进 | 但、可、问题在于、到最后、再往下、现实点看 | 把单向观点推入条件判断 |
| 中 | 自我限定 | 我会觉得、我不太明白、可能、很难说、未必 | 保留认识边界，不装权威 |
| 中 | 第二人称 | 你能不能、你会、你得、你留下什么 | 把抽象讨论变成读者可代入的处境 |
| 中 | 工作语汇 | 材料、模型、PPT、工作流、交付、领导、新人 | 给观点提供现实摩擦 |

禁止把“其实、很多时候、所以”当作口癖批量撒入。它们只在完成转折、限定或推导时出现。

## 句式规律

1. **长段落，口语句。** 段落可以容纳 4—8 个句子，但每句话仍像一个人在桌边把问题讲清楚，不写论文腔。
2. **陈述后追问。** 常见节奏是：先说观察，再连问 2—3 个问题，随后给出暂时答案。例如“效率确实更高了。可你到底留下了什么？哪些能力还在形成？”
3. **并列递进。** 高频结构为三到四项并列：“去碰材料、去搭框架、去判断对错”；并列项从动作推进到能力。
4. **概念拆对。** 不是简单赞成/反对，而是区分两件容易混在一起的事：处理信息 / 消化信息、会调用工具 / 会定义问题、审美 / taste、结果完整 / 内里站得住。
5. **自我修正。** 先承认原判断，再补条件：“这个变化当然很高效。可如果……，问题就出现了。”
6. **抽象句必须落地。** 每出现一个抽象词，附近要有工作细节、数字、材料动作或真实对话支撑。
7. **一段只推进一格。** 段落之间不是换主题，而是把同一个问题往下压一层。

## 常用句法模板

- “我最近一直在想一个词 / 一件事：____。”
- “这个说法本身就很微妙。因为在 ____ 之前，____ 原本是很自然的一部分。”
- “我又问了一个问题：如果 ____，那我们会得到什么，又会失去什么？”
- “问题在于，____ 看起来是在 ____，很多时候其实只是在 ____。”
- “再往下说，我会觉得 ____ 和 ____ 有异曲同工之意。”
- “现实点看，这不是一个纯粹的个人选择题。”
- “所以如果现在要给 ____ 赋予一点意义，我大概会说，____。”

这些是推理动作，不是必须逐字复制的开头。

## 标点与中英文混用

- 逗号密度较高，用来保留说话时的停顿；句号负责把一层判断落稳。
- 问号用于真正推进思路的追问，不用于制造营销式悬念。
- 引号用于圈定待解释的词，如“手搓”“处理后信息”“信手拈来”。
- 粗体只强调整段中的核心判断，通常是一整句或半句，不做满屏关键词加粗。
- 英文只保留三类：工作现场原词（PPT、JD、model）、中文会损失含义的概念（taste、insight）、真实引用。出现后应立即用中文解释它在本文里的意思。
- 避免“赋能、抓手、底层逻辑、时代洪流”等空转词，除非文章本身就在拆解它们。

## 语气

基调是认真、克制、有个人位置。允许困惑，但不故作脆弱；允许明确判断，但不把读者训成学生；允许口语，但不靠错别字和碎句伪装真人。作者像一个仍在问题里面的人，而不是站在终点总结方法论的人。

## 反面清单

- 不以“大背景 + 三点原因 + 价值升华”开篇。
- 不凭空写“我最近和一位前辈聊了聊”。
- 不堆万能连接词，不用“首先、其次、最后”替代真实推理。
- 不为了自然感而重复同义句、故意松散或制造错字。
- 不让英文概念承担高级感装饰。
- 不在结尾突然扩大到国家、时代、人类命运。
