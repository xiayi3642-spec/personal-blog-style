# 文章结构模板

> L2 结构分析。以下四类模板覆盖目标截图与 20 篇来源卡片中的主要写法。模板是“问题如何长出来”的路径，不是固定章节数。

## A. 聊天触发型概念随笔

适合：课堂访谈、同事交流、行业前辈谈话、团队讨论。

```text
一个最近反复出现的词或现象（100—200 字）
→ 为什么它让“我”觉得不自然
→ 交代真实谈话对象、场景和好奇心，不先替对方下结论
→ 提出第一层问题：会得到什么 / 会失去什么
→ 对方给出一个有摩擦的判断或例子
→ “我”继续追问，把问题从效率推到能力形成
→ 为模糊经验命名：手感、判断力、taste、分寸感等
→ 放入现实约束：交付、工期、组织激励、个人阶段
→ 给出条件化做法，而非唯一答案
→ 回到“我准备保留什么”
```

关键：对话是认知发生的证据，不是权威背书。没有真实谈话就改写为“我给自己提了一个问题”，不可伪造人物。

## B. 阅读触发型概念辨析

适合：读到一篇文章、一个理论、一个流行说法后继续想。

```text
看到一句让人停下来的话
→ 用自己的工作/学习场景复述它
→ 指出原说法解释不了的部分
→ 拆开两个相近概念（A 不是 B）
→ 引入最少量资料或概念，为经验命名
→ 用一个具体反例检查新解释
→ 说明这一判断如何改变自己的做法
→ 保留尚未解决的问题
```

关键：引用只负责点火，正文必须完成自己的推演；不能把文章写成读书摘要。

## C. 个人实践复盘型

适合：连续写作、课程学习、项目、工具使用、阶段性成长。

```text
一个准确而普通的事实（时间、次数、具体任务）
→ 写当时真正的感受，包括矛盾和不体面
→ 原来的解释为什么不够
→ 某次失败、反馈或小事让判断转向
→ 重新定义一个日常词
→ 解释它怎样改变下一步行动
→ 收束到个人确信，不推广为普遍成功公式
```

关键：结果只是入口，重点是判断如何变化。

## D. 现实两难 / 决策分析型

适合：效率与成长、数据与直觉、AI 与手工、短期交付与长期能力。

```text
呈现一个双方都合理的两难
→ 承认 A 的真实价值
→ 承认 B 的真实价值
→ 追问二者分别在什么条件下失效
→ 用 2—3 个场景分类，而不是站队
→ 找到更深一层的共同变量（时间、责任、判断权、反馈）
→ 给出可操作的条件判断
→ 结尾保留现实张力
```

关键：不要把“平衡”当答案。必须说清何时偏向哪一边，以及代价是什么。

## 开头库

优先级从高到低：

1. 最近的一件小事或一个反复出现的词。
2. 一句诚实的困惑或自嘲。
3. 一个准确的时间节点或工作动作。
4. 一篇文章、一段对话带来的未解决问题。

避免：宏观时代背景、百科定义、金句、先宣布全文结论。

## 转折点设计

一篇中长随笔至少出现两次真实转折：

- 第一次：原来的解释不够用了。
- 第二次：新概念也不能直接解决现实，需要加条件。

如果全文只有“举例证明开头观点”，它不是这种文风。

## 结尾方式

- 回到个人选择：“我大概还是愿意给自己留一点……”
- 落到可观察信号：“真正危险的时刻，是……”
- 留下问题，但不给空泛开放题。
- 最多上升一层，不喊口号，不“愿我们都”。
